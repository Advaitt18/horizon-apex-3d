# Horizon Apex 3D — Supercar Circuit Racing

A self-contained 3D WebGL2 arcade racing game featuring a custom real-time shadow & Fresnel clear-coat shader pipeline, Catmull-Rom spline circuit, and multi-oscillator WebAudio synthesizer.

## Playable Garage Roster
- **Ford Mustang GT Fastback** (Obsidian Black with Dual Orange Stripes • 310 KM/H)
- **BMW M4 Competition (G82)** (Isle of Man Metallic Green • 312 KM/H)
- **Bugatti Chiron Pur Sport** (Atlantic Blue & Carbon C-Line • 322 KM/H)

## Controls
- **W / S or Arrow Up / Down:** Accelerate & Brake
- **A / D or Arrow Left / Right:** Steer
- **Spacebar:** Handbrake Drift (Builds Skill Multiplier & Nitro)
- **Shift / N:** Activate Nitro / Asphalt 9 Purple Shockwave
- **C:** Cycle Camera (Chase, Action, Hood)
- **L:** Cycle Lighting Preset (Sunset, Midday, Night Neon)
- **R:** Reset Car to Track

## Running Locally or on GitHub Pages
No build step or API keys required. Open `index.html` in any modern WebGL2 browser or enable **GitHub Pages** on the repository's main branch.
